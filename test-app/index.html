📖 How to Test ApiTinker

  1. API Client: Click the API test buttons above, then open ApiTinker to see the requests in history and try sending your own requests.
  2. Mock Rules: Create mock rules in ApiTinker to intercept the API requests on this page and modify their responses.
  3. Bug Reporter: Click the console logging and error buttons, then create a bug report in ApiTinker to capture all logs and errors.
  4. Settings: Toggle dark/light mode and adjust other settings to see them persist across sessions.
